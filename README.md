## This repository contains Tutorials and Presentations on the QMC package ALF.

* For mp4 video files we are using **Git Large File Storage** ([git LFS](https://git-lfs.github.com/))

Git LFS can be locally installed, for instance, with:
```bash
curl -s https://packagecloud.io/install/repositories/github/git-lfs/script.deb.sh | sudo bash
sudo aptitude install git-lfs
git lfs track "*.mp4"
```
