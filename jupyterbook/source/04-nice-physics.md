# Reproducing some nice physics

Here we can add a number of nice  ALF  applications.  Each one of you is encouraged to do so. The ALF package is a very versatile and allows for the simulations of an ever growing number of model Hamiltonians. Aside from the basic  Hamiltonians  listed in the [ALF documentation](https://alf.physik.uni-wuerzburg.de/doc.pdf), we host a repository of  [Hamiltonains](https://alf.physik.uni-wuerzburg.de/Hamiltonians/)  where you can include your own Hamiltoinain  file.  Here we  provide a very succinct set of example runs:   Bose Einstein Condensation (as realized by the attractive Hubbard model) and Semi-metal to insulator transitions.
